# ポートフォリオ製作 演習用サンプルサイト

専門学校の授業「ポートフォリオ製作」で使用する演習用のサンプルサイトです。

## 公開URL

https://h-hamada-seifu.github.io/portfolio-samples/

## 内容

| パス | 内容 |
|---|---|
| `/` | サンプルへの入口 |
| `/a/` | サンプル A |
| `/b/` | サンプル B |
| `/c/` | サンプル C |

## 注意

**掲載されている人物・団体・作品・連絡先はすべて架空のものです。**
メールアドレスは RFC 2606 で予約されている `example.com` を使用しています。

各サンプルは授業の教材として意図的に作られたもので、実在の個人のポートフォリオでは
ありません。また、一部のサンプルには**意図的に不具合を含めてあります**（教材としての仕様です）。

## ライセンス

授業教材として作成したものです。参考にする分には自由に使ってください。
